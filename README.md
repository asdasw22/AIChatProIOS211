# Telegram Photo Drive

مشروع SwiftUI لنسخ صور iPhone احتياطيًا مباشرةً إلى محادثتك في Telegram عبر Bot API.

> مهم: توكن البوت الذي كُشف سابقًا يجب إلغاؤه فورًا من BotFather عبر `/revoke`. استخدم توكن جديد داخل التطبيق فقط.

## البنية

- `ios/`: تطبيق SwiftUI لـ iOS 17+.
- لا يوجد خادم خاص. التطبيق يرفع الصور مباشرة إلى خوادم Telegram.

## قيود iOS الواقعية

- iOS لا يسمح لتطبيق عادي بالعمل بلا توقف في الخلفية.
- الرفع الخلفي يتم ضمن آليات النظام مثل `URLSession` و `BGTaskScheduler`، والنظام يقرر متى يمنح وقتًا للتطبيق.
- إذا أغلق المستخدم التطبيق بالقوة من مبدل التطبيقات، لن يستمر التنفيذ الخلفي عادةً حتى يفتح المستخدم التطبيق مرة أخرى.
- الحذف من مكتبة الصور يتطلب صلاحية وموافقة واضحة، وقد يحذف من iCloud Photos أيضًا إذا كانت مفعلة.

## سير العمل

1. أنشئ بوت Telegram ثم ألغِ أي توكن مكشوف وأنشئ توكن جديدًا.
2. أرسل `/start` للبوت من حساب Telegram الذي سيستقبل الصور.
3. احصل على Telegram Chat ID لحسابك.
4. افتح التطبيق وأدخل Bot Token وChat ID.
5. امنح صلاحية الصور، ثم ابدأ النسخ الاحتياطي.

## كيف تحصل على Telegram Chat ID؟

بعد إرسال `/start` للبوت، افتح هذا الرابط في المتصفح مع وضع التوكن الجديد:

```text
https://api.telegram.org/botYOUR_NEW_BOT_TOKEN/getUpdates
```

ابحث عن:

```json
"chat":{"id":123456789}
```

هذا الرقم هو `Chat ID` الذي تضعه في التطبيق.

## لماذا لا نحفظ فقط آخر صورة؟

الاعتماد على آخر صورة فقط قد يفوّت صورًا إذا فشلت صورة في منتصف القائمة أو تغير ترتيب المكتبة. التطبيق يحفظ حالة كل صورة عبر `PHAsset.localIdentifier`: معلقة، قيد التجهيز، قيد الرفع، مرفوعة، أو فاشلة.

## التحقق النهائي

فحص الملفات ممكن على Windows. بناء تطبيق iOS وتصدير IPA يتطلب macOS/Xcode أو GitHub Actions macOS runner.
